# ascii-diagrams-spec

"Language specification" for ASCII-art diagrams. Readable diagrams in your markdown as plaintext, no Mermaid or other dependencies required.

## Diagram types

- [Flowchart](/flowchart.md)

## AI-ready

Just point your repo to this repo and let it generate beautiful, precise ASCII diagrams for you. Every diagram type has a skill defined in `./skills`, your agent should read it automatically.
